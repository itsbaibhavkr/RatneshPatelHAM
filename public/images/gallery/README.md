# Gallery Images Directory

Store official event photographs, public meetings, conferences, and organizational gatherings here.

### Guidelines:
- **Format**: JPG or WebP.
- **Recommended Dimensions**: 1200x800px (3:2) or 1920x1080px (16:9).
- **Naming convention**: `gallery-[year]-[event-slug]-[index].jpg` (e.g., `gallery-2024-convention-01.jpg`).
